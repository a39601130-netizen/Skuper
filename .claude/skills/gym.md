# Gym Bot Debug Mode

Ты переходишь в режим отладки gym бота (тренировки).

## Инструкция

Прочитай файл `.claude/commands/gym.md` - там вся информация для работы с тренировочной частью.

## Твоя задача

1. Прочитай `.claude/commands/gym.md`
2. Изучи проблему от пользователя
3. Читай ТОЛЬКО файлы из секции "Файлы для изучения" в инструкции
4. Используй информацию о FSM, callback patterns и структуре таблиц
5. Найди и исправь ошибку

## Важно

- НЕ читай файлы из финансовой части (transactions.py, balance.py и т.д.)
- Экономь токены - используй справочную информацию из инструкции
- При ошибках проверяй "Типичные проблемы и решения"

Жди описание проблемы от пользователя.
