# Промпт для создания Google Sheets таблицы финансового бота

## Задача

Создай оптимальную структуру Google Sheets таблицы для финансового бота на основе описания ниже. Сохрани существующие данные и инфографику, обнови формулы под новый функционал.

---

## Текущая структура таблицы

### Лист "Транзакции"

**Строка 1 - Настройки:**
- A1: "⚙️ НАСТРОЙКИ:"
- B1: "Месяц:"
- C1: номер месяца (1-12)
- D1: "Год:"
- E1: год (2026)

**Строка 3 - Заголовки:**
| Колонка | Название | Описание |
|---------|----------|----------|
| A | Дата | День месяца (1-31) |
| B | Тип | Доход/Расход/Перевод/Обмен валюты |
| C | Счёт | Счёт списания |
| D | Категория | Категория транзакции |
| E | Сумма | Сумма в исходной валюте |
| F | Счёт Куда | Счёт зачисления (для переводов) |
| G | Комментарий | Комментарий к транзакции |
| H | Полная дата | Формула: полная дата из дня+месяц+год |
| I | Часы | Часы работы (для чаевых) |
| J | Часы×6.5 | Формула: I×6.5 (расчёт по ставке) |
| K | Курс | Курс обмена валюты |
| L | BYN | Эквивалент в BYN / сумма зачисления |
| M | Валюта | Валюта операции (BYN/USD/EUR/RUB) |

**Данные начинаются со строки 4.**

---

### Лист "Счета"

**Строки 1-2:** Заголовок/инфографика
**Строка 3 - Заголовки:**
| Колонка | Название |
|---------|----------|
| A | Счет |
| B | Начальный баланс |
| C | Текущий баланс |
| D | Валюта |

**Текущие счета (строки 4+):**
- Наличные (BYN)
- Карта (BYN)
- Карта Сбер (BYN)
- На Аренду (USD)
- Копилка Тинькофф (RUB)
- На доллары (USD)
- Наличка в Рублях (RUB)

**Формула текущего баланса:** Начальный + Доходы на счёт - Расходы со счёта + Переводы на счёт - Переводы со счёта

---

### Лист "Категории"

**Строка 1 - Заголовки:**
| Колонка | Название |
|---------|----------|
| A | Тип |
| B | Категория |
| C | Бюджет |
| D | Потрачено |
| E | Остаток |
| F | Прогресс % |

**Категории доходов:**
- Зарплата
- Чаевые
- Подработка
- Другое

**Категории расходов:**
- Продукты
- Кафе
- Транспорт
- Такси
- Досуг
- Покупки
- Здоровье и красота
- Аптека
- Ништяки
- Аренда
- Коммуналка
- Интернет и связь
- Кошки
- Долги
- Одежда
- Подарки

**Формулы:**
- Потрачено: SUMIF по транзакциям где Тип="Расход" и Категория=текущая
- Остаток: Бюджет - Потрачено
- Прогресс: Потрачено / Бюджет (в процентах)

---

### Лист "Справочники"

**Строки 1-3:** Заголовки
**Строка 4+ - Данные в трёх колонках:**

| A - Типы | B - Счета | C - Категории |
|----------|-----------|---------------|
| Доход | Наличные | Зарплата |
| Расход | Карта | Чаевые |
| Перевод | Карта Сбер | Подработка |
| Обмен валюты | На Аренду | Другое |
| | Копилка Тинькофф | Продукты |
| | На доллары | Кафе |
| | Наличка в Рублях | ... (все категории) |

## Требования к новой таблице

### 1. Лист "Транзакции"

**Формула полной даты (H):**
```
=ЕСЛИ(A4="";"";ДАТА($E$1;$C$1;A4))
```
или
```
=IF(A4="","",DATE($E$1,$C$1,A4))
```

**Формула расчёта по ставке (J):**
```
=ЕСЛИ(I4="";"";I4*6.5)
```

**Условное форматирование:**
- Доход - зелёный фон
- Расход - красный фон
- Перевод - синий фон
- Обмен валюты - жёлтый фон

---

### 2. Лист "Счета"

**Формула текущего баланса для счёта в BYN:**
```
=B4
+SUMIFS(Транзакции!E:E;Транзакции!B:B;"Доход";Транзакции!C:C;A4;Транзакции!M:M;"BYN")
-SUMIFS(Транзакции!E:E;Транзакции!B:B;"Расход";Транзакции!C:C;A4;Транзакции!M:M;"BYN")
+SUMIFS(Транзакции!E:E;Транзакции!B:B;"Перевод";Транзакции!F:F;A4)
-SUMIFS(Транзакции!E:E;Транзакции!B:B;"Перевод";Транзакции!C:C;A4)
+SUMIFS(Транзакции!L:L;Транзакции!B:B;"Обмен валюты";Транзакции!F:F;A4)
-SUMIFS(Транзакции!E:E;Транзакции!B:B;"Обмен валюты";Транзакции!C:C;A4)
```

**Для мультивалютных счетов** учитывать валюту в колонке M.

**Добавить строку "ИТОГО в BYN"** с конвертацией всех валют.

---

### 3. Лист "Категории"

**Формула "Потрачено" для расходов:**
```
=SUMIFS(Транзакции!E:E;Транзакции!B:B;"Расход";Транзакции!D:D;B2;Транзакции!M:M;"BYN")
+SUMIFS(Транзакции!L:L;Транзакции!B:B;"Расход";Транзакции!D:D;B2;Транзакции!M:M;"<>BYN")
```

**Формула "Потрачено" для доходов:**
```
=SUMIFS(Транзакции!E:E;Транзакции!B:B;"Доход";Транзакции!D:D;B2)
```

**Визуальный прогресс-бар:**
Использовать спарклайны или условное форматирование для визуализации прогресса бюджета.

**Цветовая индикация:**
- 0-79% бюджета: зелёный
- 80-99% бюджета: жёлтый
- 100%+ бюджета: красный

---

### 4. Лист "Дашборд" (новый или обновить существующий)

**Показатели:**
- Общий доход за месяц
- Общие расходы за месяц
- Баланс (доход - расход)
- Общий баланс на всех счетах (в BYN)
- Топ-5 категорий расходов
- Топ категорий доходов
- Отработано часов за месяц
- Диаграмма расходов по категориям

---

## Что сохранить

1. **Все существующие транзакции** (35 записей)
2. **Балансы счетов** (начальные значения)
3. **Бюджеты категорий** (плановые суммы)
4. **Инфографику и оформление** (цвета, шрифты, границы)
5. **Именованные диапазоны** если есть

---

## Что обновить

1. **Формулы расчёта балансов** - учесть мультивалютность
2. **Формулы категорий** - учесть валютные расходы (колонка L)
3. **Формулу полной даты** - исправить если не работает
4. **Добавить валидацию данных** в колонки:
   - B (Тип) - список из справочника
   - C (Счёт) - список из справочника
   - D (Категория) - список из справочника
   - M (Валюта) - список: BYN, USD, EUR, RUB

## Контекст использования

Таблица используется Telegram-ботом для:
- Записи транзакций через `gspread` API
- Чтения справочников для выпадающих меню
- Получения статистики и отчётов
- Расчёта балансов счетов

Бот записывает данные в колонки A-M листа "Транзакции", формулы должны автоматически пересчитывать балансы и статистику.
